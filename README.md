# Тактический 2D шутер на pygame

## Структура проекта

- `main.py` — точка входа, общий цикл приложения.
- `game.py` — матч, логика раунда, обновление и рендер.
- `menu.py` — меню: старт, выбор карты, стороны и оружия.
- `map_loader.py` — тайловые карты и коллизии стен.
- `player.py` — базовый боец и игрок.
- `bot.py` — боты с ИИ (patrol / chase / attack).
- `weapon.py` — параметры оружия и фабрика.
- `bullet.py` — поведение пуль и попадания.
- `ui.py` — кнопки и отрисовка текста.
- `constants.py` — константы.
- `utils.py` — вспомогательная математика и проверки видимости.

## Запуск

1. Установите зависимости:
   ```bash
   pip install pygame
   ```
2. Запустите игру:
   ```bash
   python main.py
   ```

## Управление

- `WASD` — движение.
- Мышь — направление взгляда.
- ЛКМ — стрельба.
- `ESC` — выход в меню во время матча.

## Реализовано

- Главное меню (старт/выход).
- Выбор карты (`map1` / `map2`).
- Выбор стороны (Синие / Красные).
- Закупка оружия (Пистолет / Автомат).
- Командный матч: игрок + боты против ботов.
- Пули, урон, HP, столкновения со стенами.
- Поле зрения ~90°, ограничение дальности, блокировка стенами.
- Боты с состояниями `patrol`, `chase`, `attack`.
